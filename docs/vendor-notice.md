# Swagger UI: локальные сторонние файлы

В проект включены неизменённые статические файлы **swagger-ui-dist 5.35.0**.
Назначение: интерактивная документация `/docs` работает без внешнего CDN.
Пакет не устанавливается как зависимость; его JavaScript запускается только браузером
на странице документации. Install-скрипты npm не запускались.

- Исходный проект: https://github.com/swagger-api/swagger-ui
- Зафиксированный пакет: https://www.npmjs.com/package/swagger-ui-dist/v/5.35.0
- Метаданные npm: https://registry.npmjs.org/swagger-ui-dist/5.35.0
- Архив: https://registry.npmjs.org/swagger-ui-dist/-/swagger-ui-dist-5.35.0.tgz
- Основной проект: Apache-2.0; полный текст: `app/static/vendor/LICENSE`.
- Сохранены уведомление автора `app/static/vendor/NOTICE` и сторонние
  лицензионные уведомления `app/static/vendor/swagger-ui-bundle.js.LICENSE.txt`,
  на которые ссылается заголовок JavaScript-файла. Они взяты без изменений
  из того же зафиксированного пакета.
- Четыре исходных файла получены 2026-11-13. При подготовке этапа D добавлены
  два недостающих файла уведомлений, повторно проверены архив и все шесть файлов.

Все шесть файлов побайтово совпадают с соответствующими файлами каталога
`package/` проверенного npm-архива. Исходные bundle, CSS, favicon и LICENSE
при добавлении уведомлений не изменялись.
SHA-256 рассчитывается по исходным байтам без нормализации переводов строк.
Правило `app/static/vendor/* -text -whitespace` в `.gitattributes` сохраняет эти байты
при добавлении в Git и последующем checkout, включая Windows. Исходные пробелы
в лицензионных уведомлениях не нормализуются; контроль целостности выполняется
по точным SHA-256 вместо проверки форматирования стороннего кода.

В `/docs` должны быть заданы локальные `swagger_js_url`, `swagger_css_url`
и `swagger_favicon_url`; `validatorUrl: null` отключает обращение к внешнему
валидатору Swagger. Публикуется только каталог `/static/vendor`; интерфейс
учёта из этапа E сюда не входит. Карты исходников и ненужные примеры пакета
не включены.

## Обновление зафиксированной версии

1. Выберите конкретную версию `swagger-ui-dist`; не используйте плавающий
   `latest`. Получите метаданные этой версии из npm registry и её архив.
2. До копирования файлов проверьте SHA-512 архива по `dist.integrity` из
   метаданных. Извлеките только выбранные runtime-файлы и относящиеся к ним
   LICENSE, NOTICE и лицензионные уведомления; не запускайте npm install-скрипты.
3. Сохраните файлы пакета без изменений, пересчитайте SHA-256 всех включённых
   файлов и обновите эту таблицу, версию, ссылки и SHA-512 архива.
4. На изолированном кандидате проверьте `/docs`, `/openapi.json`, загрузку
   локальных JavaScript/CSS/favicon и выполнение API-запроса через Swagger.
   Страница должна работать без обращений к CDN или внешнему валидатору.
