## Очистка, проблемы и ограничения

- T01–T13 покрываются независимыми PostgreSQL-тестами: lifecycle, локальная доступность, архив, повторы, constraints, история, откаты, конкуренция и отчёты. T14 проверен запуском, seed, restart и сценарием панели.
- Оба P3 включены: fallback UUID при отсутствии randomUUID, сбой генератора без POST, сохранение ключа после reload, предупреждение при неопределённом изменении склада и отсутствие автоматического повтора проверены Chromium.
- Проверены пути файлов, исходники, локальные ссылки, Markdown и арифметика видео. Заглушек, закомментированных блоков реализации, TODO/FIXME/NotImplemented и create_all в приложении/миграциях нет. Кэши, окружения, node_modules, логи, браузерные результаты и реальные настройки исключены из кандидата. Рабочие настройки не читались и не удалялись.
- Исправлены устаревший отчёт и отсутствовавшая инструкция отдельной видеобазы. При ручной автоматизации короткое имя кнопки не совпало с полным aria-label; после чтения метки действие выполнено. Это не сбой приложения. Приложение и браузерные тесты прошли с первой попытки.
- Контроллер ревью не менялся; его unittest-набор в F не повторялся. Нагрузка, внешний HTTP reverse proxy и публичная эксплуатация не проверялись. Интернет нужен для первоначальной установки образов/зависимостей, а не для загруженных локальных ресурсов панели/Swagger.
- Границы: один магазин, полные операции одного SKU, без аутентификации, внешних маркетплейсов, возвратов и подтверждения доставки FBS. Без sessionStorage восстановление ограничено текущей страницей; у создания склада нет отдельного idempotency key.
- Голосовой текст — 367 слов, план около 4:20. Видео ещё должен записать человек, проверив фактический темп и читаемость.
